## 网站简介

这是我的个人博客网站，基于Jekyll和al-folio主题构建。在这里，我记录和分享我的学习笔记、旅行记忆和生活感悟。

网站地址：[https://blueberrymann.github.io](https://blueberrymann.github.io)

## 主要内容

我的博客主要包含以下内容：

- **学习笔记**：算法竞赛（如蓝桥杯、ACWing）、数据结构、编程技巧等
- **课程笔记**：自然语言处理、电子数据采集、生态经济与复垦等
- **技术分享**：实用的终端指令、编程技巧等
- **旅行记录**：旅途中的见闻和感悟
- **个人感想**：生活和学习中的思考

## 技术栈

- 静态网站生成器: [Jekyll](https://jekyllrb.com/)
- 主题: [al-folio](https://github.com/alshedivat/al-folio)
- 部署: [GitHub Pages](https://pages.github.com/)

## 本地运行

如果您想在本地运行此网站，请按照以下步骤操作：

1. 确保已安装 Ruby 和 Bundler
2. 克隆此仓库
   ```bash
   git clone https://github.com/blueberrymann/blueberrymann.github.io.git
   cd blueberrymann.github.io
   ```
3. 安装依赖
   ```bash
   bundle install
   ```
4. 启动本地服务器
   ```bash
   bundle exec jekyll serve
   ```
5. 在浏览器中访问 `http://localhost:4000`

## 目录结构

- `_posts/`: 博客文章
- `_pages/`: 网站页面
- `_projects/`: 项目展示
- `_travel/`: 旅行记录
- `assets/`: 图片、CSS、JavaScript等静态资源
- `_config.yml`: 网站配置文件
