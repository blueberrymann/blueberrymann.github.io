# 个人网站

- 之前在网站部署时，经常会出现`Prettier code formatter`的报错，只需要在push前，运行下面这行指令就可以解决

```shell
npx prettier --write .
```

# 8080端口被占用

- `windows`设备

```shell
netstat -ano | findstr :8080
```
